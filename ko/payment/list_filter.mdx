예약한 숙박에 대한 요금 안내서/청구서 역할을 하는 인보이스를 발행할 수 있습니다. 인보이스는 세금계산서나 영수증이 아닌 단순 청구서 개념입니다.

# 인보이스 자주 묻는 질문

<AccordionGroup>
  <Accordion title="인보이스(Invoice)로 세무서 신고가 가능한가요?">
    - 인보이스는 세무상 적격 증빙 서류에 해당하지 않습니다.
  </Accordion>

  <Accordion title="로고 이미지 고정 되나요?">
    - 이미지 고정 기능은 지원되지 않습니다.
  </Accordion>

  <Accordion title="숙박 기간이 필수인가요?">
    - 숫자는 없앨 수는(del 키보드) 있지만 항목을 삭제하는 것은 불가능합니다.
  </Accordion>

  <Accordion title="인보이스 문자발송되나요?">
    - 인보이스 문자발송은 지원되지 않습니다.
  </Accordion>

  <Accordion title="인보이스랑 영수증이랑 달라요?">
    인보이스 - 청구서 / 영수증 - 결제 완료 증빙
  </Accordion>

  <Accordion title="인보이스에 보이는 연락처 변경해주세요">
    처음 노출되는 고정 연락처는 변경할 수 없으며, 필요 시 수기로 변경해야합니다.
  </Accordion>

  <Accordion title="인보이스 영문 발행 시 자동 번역되나요?">
    영어,영문으로 인보이스 발행 시 자동 번역은 지원되지 않습니다. 영문으로 기재되어야하는 부분은 직접 수정하여 사용 부탁드립니다.
  </Accordion>

  <Accordion title="고객이 예약확인서(예약확정서)를 요청해요 (예약 증빙이 필요하대요 / 예약 내역 서류를 만들어 줄 수 있나요?)">
    **OTA(네이버, 야놀자 등) 예약인 경우**<br />고객이 예약한 OTA 사이트에서 직접 예약확인서(예약확정 내역)를 발급받는 것이 가장 정확합니다. 동반자 이름 추가 등 기재 내용 변경이 필요한 경우에도 해당 OTA 사이트로 문의하도록 안내해 주세요.

    **수기예약 등으로 업장에서 직접 발급해야 하는 경우**<br />클라우드(PMS)의 인보이스 발행 기능을 이용할 수 있습니다.

    1. 클라우드에서 해당 예약 찾기
    2. (필요한 경우) 예약 선택 → [수정하기]에서 예약자명 확인·수정
    3. 예약 선택 →  인보이스 발행 후 고객에게 전달

    그 외 예약확정서로 제공되는 템플릿은 없으며 원하시는 경우 업장에서 별도 템플릿을 개별적으로 만드셔서 제공해주세요.
  </Accordion>
</AccordionGroup>
