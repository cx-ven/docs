title: "미수금결제와 부속결제"
---

숙박 금액 외에 발생한 금액을 결제 내역으로 만드는 기능입니다. 시간 연장, 추가 결제, 얼리 체크인, 레이트 체크아웃 등에 사용합니다.

미수금과 부속결제는 목적이 다르지만, 만들고 확인하고 수정하고 취소하는 방법은 완전히 같습니다.

|  | 미수금 | 부속결제 |
| --- | --- | --- |
| 목적 | 실제로 결제를 받기 위해 생성 | 실 결제와 무관한 기록용 |
| 결제 시점 | **체크인 또는 체크아웃 도중에만**<br />키오스크 카드리더기로 결제 가능<br />(재실 중 결제 불가) | 결제 행위 없음 |

- **생성 후 완전 삭제는 불가능합니다.** 잘못 만드셨다면 삭제가 아니라 \*\*[결제 취소]\*\*로 처리합니다.
- **결제 날짜와 결제 메모(결제 목적)는 수정할 수 없습니다.** 바꾸시려면 [결제 취소] 후 새로 만드셔야 합니다.
- **결제 금액과 결제 수단만 수정할 수 있습니다.** 연필 아이콘으로 바로 고칠 수 있습니다.

## 만든 미수금,부속결제를 확인하고 싶어요

클라우드 하단 [내역] → 리스트에서 부속결제 [N건 보기]를 클릭하시면 하단에 상세 내역이 나옵니다.

![Image](/images/image-45.png)

1. 대시보드에서 **객실** 을 클릭 또는 **예약** 탭에서 해당 예약 건을 클릭합니다.
2. **예약 결제정보 [상세보기]** 를 클릭합니다.
3. 팝업이 뜨면 [X] 로 닫기
4. **부속결제 [n건 보기]** 를 클릭합니다. 화면이 넓은 경우 좌우 하단 가로 스크롤을 우측으로 이동하면 보입니다.
5. 하단에 부속결제 내역이 표시됩니다.

<img
  src="/images/image-30.png"
  alt="Image"
  style={{ width:"82%" }}
/>

이 화면이 **수정·취소·환불을 진행하는 화면**입니다. 아래 항목들은 모두 이 화면에서 이어집니다.

### 표시 방식

- 부속결제는 본 결제 **하위에** 추가됩니다.
- 총 결제금액에는 **본 결제 + 부속결제 금액이 합산**되어 표시됩니다.

## 금액이나 결제수단을 잘못 입력했어요

**결제 금액과 결제 수단은 취소하지 않고 바로 수정하실 수 있습니다.**

부속결제 상세 내역 화면에서,

- **결제 금액** — 금액 옆 **[연필 아이콘]** 클릭 → 금액 수정
- **결제 수단** — 결제수단 옆 **[연필 아이콘]** 클릭 → 현금 / 카드 / 계좌 / 플랫폼선결제 중 선택

**이 두 가지 외의 항목은 수정할 수 없습니다.** 다른 항목을 바꾸셔야 한다면 **[결제 취소]** 후 새로운 미수금·부속결제를 생성해 주세요.

## 미수금을 삭제하고 싶어요

**미수금과 부속결제는 완전히 삭제할 수 없습니다. 대신 [결제 취소]로 처리하시면 됩니다.**

취소한 내역은 목록에 기록으로 남지만 총 결제금액에는 반영되지 않습니다.

**취소 방법**

1. 부속결제 상세 내역 화면에서 해당 건의 **[결제 취소]** 를 클릭합니다.
2. **[결제취소]** → **[강제취소]** 중 하나를 선택합니다.

## 미수금, 부속결제를 환불해 드려야 해요

### 키오스크에서 카드로 결제받은 건

당일 카드 결제 건에 한하여, 실물 원거래 카드가 있는 조건에서만 가능합니다.<br />실제 카드 환불이 필요하므로 결제팝업을 띄워 처리합니다.

1. **[결제 취소]** 를 클릭합니다.
2. **[결제팝업 표시]** 를 선택합니다.
3. 키오스크에 "카드 삽입" 문구가 뜨면 결제했던 카드를 삽입하여 환불합니다.

### 실제 결제가 없었거나 기록만 지우면 되는 건

1. **[결제 취소]** 를 클릭합니다.
2. **[결제취소]** → **[강제취소]** 를 선택합니다.
