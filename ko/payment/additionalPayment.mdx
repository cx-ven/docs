# 부속 결제

숙박 금액 외 결제 건에 대한 내역을 생성하는 기능입니다.

- 시간 연장
- 추가 결제
- 얼리 체크인
- 레이트 체크아웃 등

결제내역 리스트에서 **부속결제 건수**를 클릭하면 하단에서 상세 내역을 확인할 수 있습니다.

![Image](/images/image-45.png)

### 부속 결제 생성하기

👉 [<kbd>부속결제 생성하기 바로가기</kbd>](https://docs.vendit.info/ko/payment/checkAdditionalPayment#%E2%85%B1-%EB%AF%B8%EC%88%98%EA%B8%88-%EB%B6%80%EC%86%8D%EA%B2%B0%EC%A0%9C-%EC%83%9D%EC%84%B1%ED%95%98%EA%B8%B0)

　

### 미수금, 부속 결제 확인 방법, 수정 방법, 삭제 방법

1. 대시보드에서 객실 또는 예약 탭에서 예약 건 클릭 → 예약 결제정보 \[상세보기\]
2. 팝업 닫기
3. 부속결제 \[1건 보기\] (보고있는 화면이 큰 경우 좌우 스크롤로 우측으로 이동) 클릭
4. 하단에 부속결제 내역 확인

<img
  src="/images/image-30.png"
  alt="Image"
  style={{ width:"82%" }}
/>

5. 미수금, 부속 결제의 수정 가능한 항목은 아래와 같으며 그 외 항목은 수정할 수 없습니다. 수정이 필요한 경우 \[결제 취소\] 후 새로운 미수금,부속결제를 생성해야 합니다.<br />- 결제금액 \[연필 아이콘\]을 클릭 → 결제 금액 수정.<br />- 결제수단 \[연필 아이콘\]을 클릭 → 현금, 카드, 계좌, 플랫폼선결제 중 택 1하여 수정.
6. 미수금, 부속 결제를 완전히 삭제할 수 없으며 \[결제 취소\]만 가능합니다.<br />결제 내역에서 취소처리 경우, \[결제 취소\] → \[결제취소\]/\[강제취소\]
7. 미수금, 부속 결제의 환불 처리는 아래와 같이 진행합니다.<br />- 키오스크를 통한 카드 결제건의 환불이 필요한 경우, \[결제 취소\] → \[결제팝업 표시\]<br />- 결제 내역에서 단순 취소처리의 경우, \[결제 취소\] → \[결제취소\]/\[강제취소\]

### 표시 방식

- 본 결제 하위에 추가됩니다.
- 총 결제금액에는 **본 결제 \+ 부속 결제 금액이 합산**되어 표시됩니다.

<Callout>
  #### ❓ 자주 묻는 질문

  <Accordion title="미수금 설정했는데 ‘프론트에서 결제’ 안내가 뜹니다">
    \[미수금 설정이 활성화 확인\]

    - 클라우드 우측 하단 \[설정\] → \[판매 및 마일리지\] → \[미수금 기능 사용\] 체크

    미수금(추가금)은 체크인 도중 또는 체크아웃 도중 결제할 수 있으며 재실 도중 결제는 불가 합니다.
  </Accordion>

  <Accordion title="미수금 수정 또는 부속결제 수정 어떻게 해요?">
    - 결제 날짜를 수정할 수 없습니다.
    - 미수금 결제 시 작성하는 메모(결제목적 (부속결제))는 결제 완료 후 수정이 불가합니다.
    - 결제금액, 결제수단은 결제 상세보기에서 "연필" 아이콘을 클릭 후 매출정보 수정을 할 수 있습니다.
  </Accordion>
</Callout>
