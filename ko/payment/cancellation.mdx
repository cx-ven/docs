## 금액이나 결제수단을 잘못 입력했어요

**결제 금액과 결제 수단은 취소하지 않고 바로 수정하실 수 있습니다.**

결제 상세내역 화면에서 좌측 "연필 아이콘"

<Frame caption='클라우드 → 결제금액, 플랫폼수수료, 결제수단 수정 "연필 아이콘" 위치 사진'>
  ![Image](/images/image-99.png "Image")
</Frame>

- **결제 금액** — 금액 옆 **\[연필 아이콘\]** 클릭 → 금액 수정
- **결제 수단** — 결제수단 옆 **\[연필 아이콘\]** 클릭 → 현금 / 카드 / 계좌 / 플랫폼선결제 중 선택
- **플랫폼 수수료 입력 기능은 예약처(플랫폼)가 ‘수기예약’이 아닌 경우에만 사용할 수 있습니다.**<br />예약 생성 시 예약처(플랫폼)를 해당 플랫폼으로 선택하면 플랫폼 수수료 입력 항목이 활성화됩니다. 기 생성된 예약은 예약 수정으로 예약처(플랫폼)을 추가 할 수 있습니다.

**이 두 가지 외의 항목은 수정할 수 없습니다.** 다른 항목을 바꾸셔야 한다면 **\[결제 취소\]** 후 새로운 미수금·부속결제를 생성해 주세요.

**또한 금액 수정은 클라우드 내 기록만 변경됩니다.**<br />결제 금액 수정은 클라우드에 기록된 결제 내역을 수정하는 기능으로, 실제 결제에는 아무런 영향을 주지 않습니다.

- 카드로 결제된 금액이 변경되거나 승인 취소되지 않습니다.
- OTA 등 예약 사이트에 등록된 결제 금액도 변경되지 않습니다.

실제 결제 금액을 변경해야 하는 경우에는 \[결제 취소\] 후 다시 결제를 진행해 주세요.

---

#### 결제 일자를 수정할 수 있나요?

- 결제 내역이 생성된 일자는 수정할 수 없습니다.
- 원하시는 결제 일자에 예약을 새로이 생성하시거나 부속결제로 추가 생성해야합니다.
