## 결제 정산통계 표

조회를 원하는 날짜의 매출 통계를 확인할 수 있습니다.

<Frame caption="클라우드 → 결제정산 → 정상통계 표 사진">
  ![Image](/images/image-103.png "Image")
</Frame>

우측 필터 [정산통계 접기]로 상단 통계 영역을 숨기거나 다시 표시할 수 있습니다.

정산통계는 예약이 생성된 경로에 따라 세 영역과 전체 합계로 나뉘며, 각 통계는 예약타입(대실/숙박)별 건수와 매출 금액을 보여줍니다.

- **현장 (키오스크) 정산통계** : 현장에서 키오스크를 통해 결제한 예약의 건수와 매출 합계. 현금매출 / 카드매출 / 기타매출로 구분됩니다.
- **수동입력 (프론트) 정산통계** : 업장에서 수기로 생성한 예약의 건수와 매출 합계. 현금매출 / 카드매출 / 기타매출로 구분됩니다.
- **기타 (플랫폼 자동예약, 부킹엔진) 매출 통계** : 예약 자동 연동을 통해 생성된 예약의 건수와 매출 합계. 플랫폼선결제 / 부킹엔진 / 컨시어지 / 기타로 구분됩니다.
- **전체 매출 합계** : 위 세 영역을 모두 포함한 전체 예약의 건수와 매출 합계. 우측 상단에서 취소된 내역 수, 취소 금액, 미수금을 함께 확인할 수 있습니다.

ℹ️ **기타매출**: 마일리지, 플랫폼선결제, 계좌이체, 컨시어지 결제 건이 포함됩니다.<br />ℹ️ **부킹엔진**: 예약 건별로 결제방법이 서로 다를 수 있습니다.<br />ℹ️ 각 통계 우측 상단의 **미수금**은 해당 영역에서 아직 수납되지 않은 금액입니다. 합계 금액에 포함되지 않습니다.<br />ℹ️ <u>건</u> : 결제 내역 건수가 아닌, 예약 건의 수를 의미합니다.<br />ℹ️ <u>원</u> : 결제 내역의 합계 금액을 의미합니다.

<AccordionGroup>
  <Accordion title="1. 플랫폼별 수수료">
    수수료 포함 / 수수료 미포함<br />결제 상세정보에서 결제 금액의 수수료 포함 또는 미포함 노출 설정을 할 수 있습니다.

    - CMS 사용 업장 : OTA에서 정보를 제공하지 않는 경우 노출되지 않습니다. 수수료를 제공하지 않는 OTA는 설정 → 계정관리 → 계정 연동 시 수수료를 설정할 수 있습니다.
    - VCMS 사용 업장 : 채널 → 연동된 OTA → 수수료를 설정할 수 있습니다.
    - TL 사용 업장 : TL측으로 문의해주세요.
  </Accordion>

  <Accordion title="2. 입실일시 / 결제일시">
    - 입실일시 = 체크인 일시
    - 결제일시 = 예약이 클라우드에 생성된 일시
    - 검색 날짜는 최대 30일만 가능
  </Accordion>

  <Accordion title="3. 결제경로">
    - 선택안함 : 전체
    - 수동(프론트) : 프론트에서 수기로 결제 내역 생성
    - 자동(플랫폼) : OTA 예약 연동 시 자동으로 결제 내역 생성
    - 키오스크 : 키오스크에서 결제
    - 부킹엔진 : 부킹엔진 사이트에서 결제
    - 미수금/부속결제가 결제정산 내역에 보이지 않는다면 오른쪽 결제경로 필터에서 "부속결제 함께 보기"를 체크해주세요
  </Accordion>

  <Accordion title="4. 결제방식">
    - 신용카드
    - 현금
    - 마일리지
    - 플랫폼

    <Accordion title="플랫폼 뒤 괄호 안의 노출 채널명, 결제 방식에서 표기되는 플랫폼의 채널명">
      "플랫폼" 뒤 괄호 안에는 해당 예약이 어떤 채널을 통해 들어왔는지가 표기됩니다.<br />(예: 플랫폼(야놀자), 플랫폼(NOL))

      같은 계열의 예약 사이트라도 업장에서 사용는 예약 수신 연동 주체에 따라 표기가 달라질 수 있습니다.

      유입 경로는 예약 상세의 "예약처(플랫폼)" 항목에 기재된 태그 — (VCMS, CMS) 또는 (TlLincoin) — 로 확인할 수 있습니다.

      결제 내역의 결제 건을 클릭하면 가운데에 간단 예약 상세 내역에서도 확인할 수 있습니다.
