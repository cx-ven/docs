## 결제 정산

매출 통계를 확인할 수 있습니다.

### 정산통계 표로 확인 가능 항목

- 현장(키오스크) 매출
- 수동(프론트) 매출
- 플랫폼 / 부킹엔진 매출
- 전체 매출 합계

  <Accordion title="플랫폼별 수수료" icon="1">
    수수료 포함 / 수수료 미포함\
    결제 상세정보에서 결제 금액의 수수료 포함 또는 미포함 노출 설정을 할 수 있습니다.

    - CMS 사용 업장 : OTA에서 정보를 제공하지 않는 경우 노출되지 않습니다. 수수료를 제공하지 않는 OTA는 설정 → 계정관리 → 계정 연동 시 수수료를 설정할 수 있습니다.
    - VCMS 사용 업장 : 채널 → 연동된 OTA → 수수료를 설정할 수 있습니다.
    - TL 사용 업장 : TL측으로 문의해주세요.
  </Accordion>

  <Accordion title="입실일시 / 결제일시" icon="2">
    - 입실일시 = 체크인 일시
    - 결제일시 = 예약이 클라우드에 생성된 일시
    - 검색 날짜는 최대 30일만 가능ㄹ
  </Accordion>

  <Accordion title="결제경로" icon="3">
    - 선택안함 : 전체
    - 수동(프론트) : 프론트에서 수기로 결제 내역 생성
    - 자동(플랫폼) : OTA 예약 연동 시 자동으로 결제 내역 생성
    - 키오스크 : 키오스크에서 결제
    - 부킹엔진 : 부킹엔진 사이트에서 결제
  </Accordion>
