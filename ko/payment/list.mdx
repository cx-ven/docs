결제 내역 메뉴에서는 고객의 결제 정보 확인, 취소, 환불 및 정산 관리를 할 수 있습니다.

## 결제내역 리스트

- 고객의 전체 결제 내역을 확인할 수 있습니다.
- 상단 [ **표시/순서 변경 ∨** ]
  결제 내역 목록에 표시되는 항목과 순서를 원하는 대로 설정할 수 있습니다. 우측 상단의 [표시/순서 변경]을 클릭하면 설정 영역이 열립니다.
  **표시할 정보 선택**<br />[표시할 정보]에서 체크박스를 켜고 끄면 해당 항목이 목록에 표시되거나 숨겨집니다. 입실일시, 퇴실일시, 결제일시, 예약타입, 객실타입, 배정호실, 결제자명, 결제금액, 결제경로, 결제방식, 결제상태, 거래번호, 부속결제 등 필요한 항목만 선택해 보실 수 있습니다.
  **표시 순서 변경**<br />[표시정보 순서변경] 영역에서 항목 버튼을 드래그하면 목록에 표시되는 열(컬럼) 순서가 그 순서대로 변경됩니다. 자주 확인하는 항목을 앞쪽으로 배치해 보세요.
  **초기화**<br />[초기화] 버튼을 누르면 표시 항목과 순서가 기본 설정으로 되돌아갑니다.
- 상단 **[조회내역 내보내기]** 클릭 시 엑셀 파일로 다운로드할 수 있습니다.

<Warning>
  주의사항

  - 다운로드 파일에는 **현재 조회된(화면에 보여지) 내역만 포함**됩니다.
  - 전체 기간 내역이 자동으로 다운로드되지 않습니다.
</Warning>

<AccordionGroup>
  <Accordion title="1. 플랫폼별 수수료">
    수수료 포함 / 수수료 미포함<br />결제 상세정보에서 결제 금액의 수수료 포함 또는 미포함 노출 설정을 할 수 있습니다.

    - CMS 사용 업장 : OTA에서 정보를 제공하지 않는 경우 노출되지 않습니다. 수수료를 제공하지 않는 OTA는 설정 → 계정관리 → 계정 연동 시 수수료를 설정할 수 있습니다.
    - VCMS 사용 업장 : 채널 → 연동된 OTA → 수수료를 설정할 수 있습니다.
    - TL 사용 업장 : TL측으로 문의해주세요.
  </Accordion>

  <Accordion title="2. 입실일시 / 결제일시">
    - 입실일시 = 체크인 일시
    - 결제일시 = 예약이 클라우드에 생성된 일시
  </Accordion>

  <Accordion title="3. 객실타입">
    특정 객실 타입 결제 내역 조회
  </Accordion>

  <Accordion title="4. 예약 객실타입">
    최초 생성된 예약 객실 타입을 기준으로 예약 상세의 객실 타입을 표시합니다.
  </Accordion>

  <Accordion title="5. 결제경로">
    - 수동(프론트) : 프론트에서 수기로 결제 내역 생성
    - 자동(플랫폼) : OTA 예약 연동 시 자동으로 결제 내역 생성
    - 키오스크 : 키오스크에서 결제
    - 부킹엔진 : 부킹엔진 사이트에서 결제
  </Accordion>
