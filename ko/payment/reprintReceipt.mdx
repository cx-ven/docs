# 결제 영수증 재출력하기

- 클라우드 내 \[내역\] → 결제 건 선택 → \[영수증 재출력\] 클릭 후 출력을 원하는 키오스크를 선택해 결제 영수증을 재출력합니다.

# 입실 호수 영수증만 재출력하기

- 입실 호수 영수증만 재출력하는 기능은 현재 지원되지 않습니다.
