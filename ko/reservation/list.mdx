# 예약 메뉴

우측 세로 퀵 네비게이션 메뉴 바는 마우스를 올려 활성화합니다.

  width="500"
/>

- 당일 예약
- 미리 예약
- 전체 예약

<img
  src="/images/예약_검색,리스트표시,순서변경.png"
  width="700"
/>

#### 전체예약 → 왼쪽 검색 기능

좌측 상단 검색 창에 다음 정보로 검색 가능합니다.

- 연락처
- 예약자명
- 예약번호(4자리)

#### 전체예약 → [ **표시/순서 변경 ∨ ]**

예약 조회 리스트의 표시 정보를 변경하거나 순서를 설정할 수 있습니다.

- 표시/순서 변경
  전체 예약 목록에 표시되는 항목과 순서를 원하는 대로 설정할 수 있습니다. 우측 상단의 [표시/순서 변경]을 클릭하면 설정 영역이 열립니다.
  **표시할 정보 (선택)**<br />[표시할 정보]에서 체크박스를 켜고 끄면 해당 항목이 목록에 표시되거나 숨겨집니다. OTA No, 예약 객실 타입, 배정객실, 인원, 예약타입, 예약일시, 투숙기간, 예약처, 예약자명, 연락처, 차량정보, 예약상태, 얼리체크아웃, 메모, 병합 이름, 결제금액, 미수금 등 필요한 항목만 선택해 보실 수 있습니다.
  **표시정보 순서변경 (드래그)**<br />[표시정보 순서변경] 영역에서 항목 버튼을 드래그하면 목록에 표시되는 열(컬럼) 순서가 그 순서대로 변경됩니다. 자주 확인하는 항목을 앞쪽으로 배치해 보세요.
  표시할 정보 **[초기화]**<br />[초기화] 버튼을 누르면 표시 항목과 순서가 기본 설정으로 되돌아갑니다.

# 예약 상세보기

**예약 내역 조회, 예약처 및 결제정보 확인, 예약 수정 및 예약 취소**를 할 수 있습니다.

- **기본정보**: 예약번호, 예약타입, 객실타입, 배정객실(미배정 시 배정 가능), 입실인원, 예약일시, 예약경로(자동/수동), 입·퇴실시간, 총 숙박기간, 예약처, 차량방문 정보 확인
- **상세정보**: 예약자명, 연락처, 예약 메모 확인
- **결제정보**: 결제금액, 결제경로, 결제수단, 결제상태, 마일리지 적립내역, 결제일시 확인 가능하며, 클릭 시 **결제내역 페이지**로 이동합니다.
