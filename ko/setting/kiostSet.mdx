# 시스템 설정

![Image](/images/설정_키오스크_시스템설정.png)

<AccordionGroup>
  <Accordion title="1. 청소 설정">
    - **자동 청소지시 비활성화** : 활성화 시, 키오스크에서 체크아웃하더라도 대시보드에서 자동 청소 지시로 변경되지 않습니다.
    - **청소 지시 후 전원 차단** : 활성화 시, 청소 지시로 변경 후 객실 내 공급되는 전기를 차단합니다. (지원 가능한 CCU만 가능 - 키 텍으로 전원 차단,공급이되며 벤디트와 연동 가능한 CCU만 지원)
    - **객실 점검 비활성화** : 활성화 시, 객실 점검 상태를 사용하지 않습니다.
    - \*\*차량 출차버튼 비활성화 **:** \*\*활성화 시, 차량 출차버튼을 제공하는 RCU (더엠알, 아이크루)에서 차량 출차버튼을 전체 비활성화 처리하며, 차량 출차 버튼을 눌러도 아무런 동작이 일어나지 않도록 합니다.
    - \*\*차량방문여부 확인 **:** \*\*활성화 시 손님이 체크인 할 때 차량 방문 여부를 확인하도록 설정합니다.
  </Accordion>

  <Accordion title="2. 자동 재시작 (0일로 설정시 사용 안함)">
    키오스크 PC내 벤디트 프로그램을 자동 재시작하는 기능입니다.
  </Accordion>
</AccordionGroup>

    - **체크인시 객설 번호 미출력** : 영수증 출력 시 입실 정보 (사업장 정보, 입실시간, 퇴실시간)만 출력되며 객실 번호는 출력되지 않습니다.

    **2번 현금 방출기** - 키오스크를 정면으로 봤을 때 오른쪽 함의 방출 권종을 설정합니다.

    - 설정 가능한 권종은 5만원, 1만원, 5천원, 천원 입니다.
    - 두 방출기의 권종이 동일한 경우 오류가 발생 될 수 있습니다. 1번/2번 현금 방출기는 다른 권종으로 설정 해주세요.
  </Accordion>

### ❓자주 묻는 FAQ

<Accordion title="벤디트의 '예약 번호' , 'QR 코드'로 체크인을 위해선 문자 발송을 해야하나요? 비용이 발생하지 않는 체크인 방법이 있나요?">
  예약자명으로 체크인을 사용하시면 별도의 문자 안내/발송 없이 바로 예약 체크인이 가능합니다.현재 안내된 문자를 통한 예약 체크인 방식은

  '예약 번호'와 'QR코드' 두 가지입니다.

  1. 안내된 문자를 통한 예약 체크인 방식

  - 예약 번호로 조회
  - QR코드로 조회

  2. 안내 문자 없이 가능한 예약 체크인 방식

  - 예약자명으로 조회
</Accordion>
