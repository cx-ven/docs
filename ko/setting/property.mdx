![Image](/images/설정_계정및일반.png)

<AccordionGroup>
  <Accordion title="1. 지점 문의전화 번호">
    키오스크 화면 아래쪽에 노출되는 문의전화 번호를 설정 하실 수 있습니다.<br />즉각적인 반영을 원하시는 경우 클라우드 \[대시보드\] → 좌측 상단 "동작중" 옆의 키오스크 선택 → \[키오스크 재시작\] 버튼으로 키오스크 프로그램을 재실행 해주세요.<br />\*변경시 키오스크 관리자모드 진입 시에 필요한 비밀번호도 변경이 됩니다.
  </Accordion>

  <Accordion title="2. 기본 체크인 / 기본 체크아웃 시간">
    설정 → 객실에서 설정된 체크인/체크아웃 시간이 없다면 해당 시간을 따라갑니다.
  </Accordion>

  <Accordion title="3. 알림메일 수신주소">
    성인인증 시, 손님이 제출한 신분증/사진이 첨부되어 메일로 전송됩니다.<br />최대 3개까지 수신 이메일 등록이 가능합니다
  </Accordion>

  <Accordion title="4. 알림문자 수신번호">
    키오스크 현장 결제 시, 성인인증 직원승인 시, 자동문자 충전 알림, 공지사항 등을 수신할 수 있습니다.<br />최대 3개까지 수신 연락처 등록이 가능합니다.
  </Accordion>

  <Accordion title="5. 간편 로그인">
    핀번호로 로그인 : V-CLOUD 앱(안드로이드만 지원) 로그인 시 사용  합니다,
  </Accordion>

  <Accordion title="6. 계정 옵션">
    - **비밀번호 변경 :** 로그인한 계정의 비밀번호를 변경할 수 있습니다
    - **전체 기기 로그아웃 :** 현재 로그인된 계정으로 로그인된적 있는 기기에서만 전체 로그아웃됩니다. 다른 계정의 로그아웃은 지원되지 않습니다.<br />다른 계정의 로그아웃이 필요할 경우 해당 계정으로 재로그인하여 전체 기기 로그아웃 진행이 필요합니다.
  </Accordion>
</AccordionGroup>
