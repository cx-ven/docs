# 예약 추가 버튼으로 예약 만들기

<Frame caption="클라우드(PMS)/대시보드→예약추가 버튼으로 예약만드는 방법">
  <img
    src="/images/대시보드,예약_예약추가.png"
    width="700"
    alt="대시보드,예약_예약추가"
    className="mx-auto"
  />
</Frame>

<AccordionGroup>
  <Accordion title="1. 대실 포함 / 미포함" iconType="sharp-solid">
    > 대실 판매를 하지 않는 경우 해당 옵션을 비활성화하여 **대실 관련 메뉴를 숨길 수 있습니다.**<br />설정은 **현재 사용 중인 장치에 저장되며**, 이후에도 동일하게 적용됩니다.
  </Accordion>

  <Accordion title="2. 객실 타입">
    > 예약할 **객실 타입**을 선택합니다.<br />패키지가 설정된 지점의 경우 **\[패키지판매\]** 체크 시 패키지 타입으로 예약할 수 있습니다.
  </Accordion>

  <Accordion title="3. 입실 / 퇴실 시간">
    > 예약의 입실 및 퇴실 시간을 설정합니다.
  </Accordion>

  <Accordion title="4. 기간 빠른선택, 이용시간 조절">
    > 기간 빠른선택/이용시간 조절 버튼으로 입/퇴실 시간을 편리하게 조절합니다.
  </Accordion>

  <Accordion title="5. 투숙 형태, 입실인원">
    > 예약의 투숙 형태 및 입실할 인원 수를 입력합니다.
  </Accordion>

  <Accordion title="6. 결제 정보">
    > -결제 금액<br />-결제 구분 (선결제 / 현장결제 등)<br />-미수금 입력 가능<br />※ \[마일리지 제외\] 체크 시 해당 예약은 마일리지 적립 대상에서 제외됩니다.
  </Accordion>

  <Accordion title="7. 예약처 (플랫폼)">
    > 예약이 유입된 경로를 선택합니다.<br />"수기예약" 외 예약처 추가 시 프로필관리에서 추가할 수 있습니다.<br />프로필관리 → 컴퍼니 프로필 관리 → 좌측 플랫폼 추가<br />플랫폼 이름 수정 후 "저장하기"를 눌러주세요. 그 외 다른 설정은 하지 않아도 됩니다.
    >
    > <Frame caption="클라우드(PMS)/수기 예약추가 시 예약처를 추가하는 방법→프로필관리→컴퍼니 프로필 관리 → 좌측 플랫폼 추가">
    >   ![Image](/images/image-33.png)
    > </Frame>
  </Accordion>

  <Accordion title="8. 예약번호">
    > 키오스크 입실 시 사용할 4자리 예약번호를 입력합니다.<br />OTA 예약의 경우 예약번호 끝 4자리 입력을 권장합니다.
  </Accordion>

  <Accordion title="9. 고객 정보">
    > -예약자명<br />-연락처<br />-차량 방문 여부<br />-메모
  </Accordion>

  <Accordion title="10. 예약 옵션">
    > 예약문자 발송 체크 시, 입력된 연락처로 예약 안내 문자가 발송됩니다.

    <Callout icon="warning">
      1.예약옵션에 체크가 없을 경우 연락처가 있더라도 자동 문자가 발송되지 않습니다.

      2.자동 문자를 사용하지 않는 경우 문자가 발송되지 않습니다.

      3.자동 문자는 유료서비스 입니다.

      👉 [<kbd>자동문자 바로가기</kbd>](https://ven-5828dcc8.mintlify.app/ko/setting/SMS) 클릭
    </Callout>
  </Accordion>
</AccordionGroup>

모든 정보를 입력한 후 **\[예약 추가하기\]** 버튼을 클릭하면 예약과 결제 내역이 함께 생성됩니다.

# 대시보드에서 특정 호수를 선택하고 예약 만들기

<Frame caption="클라우드(PMS)/대시보드→호수클릭하고 예약만드는 방법">
  <img
    src="/images/대시보드_공실객실_상세보기.png"
    alt="Image"
    title="Image"
    style={{ width:"88%" }}
  />
</Frame>

<AccordionGroup>
  <Accordion title="1. 키오스크 판매상태">
    요금 설정과 무관하게 키오스크 \*\*현장판매(워크인) \*\*상태를 설정할 수 있습니다.

    > **-** **전체** : 현재 예약이 있을 경우 강제 퇴실 처리<br />**-** **숙박만** : 요금설정과 무관하게 키오스크에서 숙박만 판매<br />**-** **대실만** : 요금설정과 무관하게 키오스크에서 대실만 판매<br />**-** **판매중지** : 키오스크에 객실을 선택할 수 없게 설정. 객실 판매 중지 기능과 무관
    >
    > <Callout icon="triangle-exclamation" color="#cd4b4b">
    >   **\[판매중지\] 주의사항**
    >
    >   **키오스크 판매 중지** : 키오스크에 객실을 선택할 수 없게 설정. 객실 판매 중지 기능과 무관
    >
    >   **객실 판매 중지** : 객실에 문제가 있어 예약이 배정 불가하도록 설정
    > </Callout>
  </Accordion>

  <Accordion title="2. 객실상태">
    객실 상태 선택 박스를 통해 상태를 변경할 수 있습니다.<br />**객실 상태 변경 후 새로고침(F5)를 실행해주세요.**

    > - **공실**: 현재 예약이 있을 경우 강제 퇴실 처리 <br />- **전원 차단**: 객실 전원 차단 (일부 장치 미지원)<br />- **청소지시**: 청소 요청 (완료 시 기존 상태로 복구)<br />- **긴급청소**: 대시보드에서 강조 표시되는 청소 요청<br />- **숙박 / 대실**: 예약 유형 변경<br />- **청소중**: 키홀더 미설치 업장에서 수동 표시<br />- **판매중지**: 객실에 문제가 있어 예약 배정 불가 및 판매 불가하도록 설정<br />- **퇴실**: 사용 종료 처리 (예약/결제 취소되지 않음)<br />- **사용취소**: 예약 및 결제 전체 취소 후 상태 초기화
    >
    > <Callout icon="triangle-exclamation" color="#cd4b4b">
    >   **\[판매중지\] 주의사항**
    >
    >   **키오스크 판매 중지** : 키오스크에 객실을 선택할 수 없게 설정. 객실 판매 중지 기능과 무관
    >
    >   **객실 판매 중지** : 객실에 문제가 있어 예약이 배정 불가하도록 설정
    > </Callout>
  </Accordion>

  <Accordion title="3. 마지막 예약 조회하기">
    해당 호수에서 가장 마지막에 체크아웃했던 예약 정보를 확인합니다.
  </Accordion>

  <Accordion title="4. 마지막 사용상태 복구하기">
    실수로 공실 처리된 객실을, 마지막으로 입실했던 손님의 예약·재실 상태로 되돌릴 수 있습니다. 관리자 오조작이나 청소 담당자의 착오로 예약이 잘못 종료됐을 때 사용할 수 있습니다.
  </Accordion>

  <Accordion title="5. [이용중표시] 탭에서 예약 바로 생성하기">
    공실인 객실을 대시보드에서 선택 후 예약을 만들 수 있습니다.

    해당 탭에서 예약을 직접 생성하여 \[저장\] 시 별도 체크인 처리 없이 자동으로 체크인처리가 되벼, 우측 기록에 "대실 이용중으로 변경", "숙박 이용중으로 변경" 으로 확인됩니다.
  </Accordion>
</AccordionGroup>
