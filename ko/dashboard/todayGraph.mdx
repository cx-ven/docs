## 오늘매출은 어떤 정보가 보여지는건가요?

> \[내역\] → 우측 \[결제 정산\] → \[입실일시\] 기준의 정보가 표기됩니다.

## 예약 외 매출이란?

> #### 당일 입실건이 아닌 예약에서 결제가 발생한 건에 대한 매출입니다.
>
> 대시보드에서 보는 \[오늘매출\]의 경우 당일 입실 예약에서 발생한 매출을 집계합니다.
>
> 만약 당일 입실 건이 아닌 재실 예약건에서 결제가 발생했을 경우 “예약 외 매출” 로 집계 됩니다.
>
> - \[내역\] → 우측 메뉴 \[결제 정산\] → \[입실일시\]로 조회되는 목록에서 "결제 일시"는 당일이지만 입실 일시가 당일이 아닌 경우 예약 외 매출로 집계됩니다.

## 매출 발생 날짜 변경 여부

1. 매출 일자는 수정이 불가합니다.
2. 결제 생성 일자는 수정이 불가합니다.

과거 일자로 수정할 수 없으며, 당일 집계가 필요한 경우 당일에 수기 예약 생성 또는 부속 결제로 생성해야합니다.

---

## "당일" 기준 설정

- "오늘" 매출의 기준 시각은 대시보드 하단 \[설정\] → 우측 메뉴 \[판매 및 마일리지\] → \[일 매출표 초기화 기준 시간\]에서 설정합니다. 가능합니다
- \[실제 입실 시간\]이 아닌 예약 생성 시 설정된 \[입실 예정 시간\](=체크인 예정 시각)이 기준이 됩니다. 실제 입실 시간을 기준으로 할 경우, 늦은 체크인 건이 익일 매출로 반영될 수 있어 위 기준을 적용합니다.
  ※ 실제 입실 시간은 고객이 현장에서 체크인 완료한 시각이며, 매출 기준에는 반영되지 않습니다.
