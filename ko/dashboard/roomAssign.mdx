오늘 입실 예정이며 객실이 미배정된 예약이 있는 경우, **대시보드 \> 다가오는 예약** 영역에서 예약 카드를 확인하고 객실을 배정할 수 있습니다.

- 오늘 체크인 예약과 현재 시점 기준 24시간 이내 체크인 예정 예약만 노출됩니다.<br />→ 익일 예약 숨기기 체크 해제 시, 지금 시점을 기준으로 24시간 이내의 내일 체크인 예약 건이 다가오는 예약에 함께 뜹니다.
- 예약이 많은 경우에는 다가오는 예약 리스트 영역에 마우스 올린 후→ 스크롤하여 확인 (위/아래 또는 좌/우)

# 예약 배정부터 룸 체인지 방법

아래 기능을 배울 수 있습니다.

1. 다가오는 예약 배정
2. 강제 배정 (예약 객실과 배정 객실의 타입이 다를 때)
3. 체크인 전 룸 체인지

예약 카드를 이동할 때 객실 상태에 따라 다음과 같이 표시됩니다.

<Callout icon="bird">
  - 매우 어두움: 배정 불가 객실 (놓아도 적용되지 않음)
  - 약간 어두움: 배정 가능하나 객실 타입 불일치 → 배정 시 확인 창이 표시됨
  - 밝게 표시: 타입 일치 및 배정 가능
  - 공실: 즉시 배정
  - 기존 예약 있음: 예약 병합 화면 표시 후 확인 시 병합 처리
</Callout>

## 선배정이 가능한가요?

![Image](/images/대시보드_선배정.png)

![Image](/images/대시보드_선배정.png)

선배정은 \[다가오는 예약\]에 예약 카드가 있는 경우에만 가능합니다.<br />배정을 원하는 객실의 상태가 \[청소지시\] , \[청소중\] 일 때 예약 건을 드래그 & 드롭합니다.

\[예약 선배정\] 팝업이 노출되면 \[배정하기\] 클릭하여 선배정을 마무리합니다.

# 병합이란?

대시보드에서 노출되는 예약 (다가오는 예약) 건들에 한하여 “병합”이 가능합니다.

![Image](/images/image-17.png)

![Image](/images/image-17.png)

![Image](/images/image-17.png)

병합 요청 : 병합 시키는 예약 건<br />병합 진행 : 병합되는 주체의 예약 건

- 병합된 예약이 숙박 예약이라면 재고를 차감합니다.
- 이미 병합된 예약은 다른 예약에 병합할 수 없습니다.
- 병합 시 정산은 앞선 예약건의 입실 날짜로 정산 내역이 집계됩니다. 예약의 실제 입실일 기준으로 정산이 되기 때문입니다.<br />예) 101호가 → 102호로 병합되고, 병합된 102호는 → 103호로 병합이 불가능<br />103호는 → 102호로 병합 가능

## 병합 취소하는 방법

- 클라우드 내 대시보드에서 객실 선택 → \[예약 병합 내역\] 버튼 클릭 → \[병합 취소\] 버튼으로 취소 해주세요.
- 또는 예악 건 상세보기 우측 \[예약 병합 내역\] 버튼 클릭 → \[병합 취소\] 버튼으로 취소 해주세요.
