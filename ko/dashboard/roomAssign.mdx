- 오늘 체크인 예약과 현재 시점 기준 24시간 이내 체크인 예정 예약만 노출됩니다.<br />→ 익일 예약 숨기기 체크 해제 시, 지금 시점을 기준으로 24시간 이내의 내일 체크인 예약 건이 다가오는 예약에 함께 뜹니다.
- 예약이 많은 경우에는 다가오는 예약 리스트 영역에 마우스 올린 후→ 스크롤하여 확인 (위/아래 또는 좌/우)

# 체크인 전에 방 바꾸기 (예약 배정 · 룸 체인지)

아래 기능을 배울 수 있습니다.

1. 다가오는 예약 배정
2. 강제 배정 (예약 객실과 배정 객실의 타입이 다를 때)
3. 체크인 전 룸 체인지

예약 카드를 이동할 때 객실 상태에 따라 다음과 같이 표시됩니다.

<Callout icon="bird">
  - 매우 어두움: 배정 불가 객실 (놓아도 적용되지 않음)
  - 약간 어두움: 배정 가능하나 객실 타입 불일치 → 배정 시 확인 창이 표시됨
  - 밝게 표시: 타입 일치 및 배정 가능
  - 공실: 즉시 배정
  - 기존 예약 있음: 예약 병합 화면 표시 후 확인 시 병합 처리
</Callout>

# 잘못 체크인했어요 — 입실대기로 되돌리기 (배정취소)

배정취소는 객실에 배정된 예약을 미배정 상태로 되돌리는 기능입니다. 체크인이 잘못 처리된 경우 이 기능으로 입실대기 상태로 복구할 수 있습니다.

<Check>
  CCU(키텍) 연동 업장은 객실 키 홀더에 키가 꽂혀 있으면 배정을 취소해도 다시 숙박중으로 바뀝니다. 배정취소 전에 키를 먼저 빼주세요.
</Check>

1. 대시보드에서 잘못 체크인 된 객실 클릭 → \[예약정보 조회\]<br />→ 상세보기에서 왼쪽 배정 객실 옆 \[배정취소\] 클릭 → \[확인\]<br />→ 대시보드에서 F5로 새로고침 → 취소된 예약은 미배정 상태가 되어 \[다가오는 예약\] 목록에 표시됩니다.
2. 배정만 취소하면 객실은 "이용만료"로 남습니다.<br />"이용만료"상태인 객실 클릭 → "이용만료" 상태 박스 클릭 → \[공실\] 선택 / 청소가 필요하면 공실 대신 \[청소지시\]를 선택합니다.
3. \[다가오는 예약\]에서 예약을 원하는 객실로 끌어다 놓습니다. 정상 배정되면 "수동배정"(=입실대기) 상태가 됩니다.

## 선배정이 가능한가요?

![Image](/images/대시보드_선배정.png)

선배정은 \[다가오는 예약\]에 예약 카드가 있는 경우에만 가능합니다.<br />배정을 원하는 객실의 상태가 \[청소지시\] , \[청소중\], \[점검지시\], \[점검중\] 일 때 예약 건을 드래그 & 드롭 합니다.

\[예약 선배정\] 팝업이 노출되면 \[배정하기\] 클릭하여 선배정을 마무리합니다.

객실 상태가  \[긴급청소\] 인 경우엔 선배정이 불가합니다

<Callout icon="triangle" color="#e15b5b">

# 병합이란?

예약 병합 기능은 "한 손님의 서로 다른 연박의 예약건을 하나의 투숙으로 묶어, 손님은 방 이동 없이 이어서 이용할 수 있는 기능 입니다.

대시보드에서 노출되는 예약 (다가오는 예약) 건들에 한하여 “병합”이 가능합니다.

<img
  src="/images/image-69.png"
  alt="Image"
  title="Image"
  style={{ width:"64%" }}
/>

- 병합된 예약이 숙박 예약이라면 재고를 차감합니다.
- 이미 병합된 예약은 또 다른 예약과 병합할 수 없습니다. (병합은 최대 2개까지만 가능합니다.)<br />예) 101호가 → 102호로 병합되고, 병합된 102호는 → 103호로 병합이 불가능<br />103호는 → 102호로 병합 가능
- 병합 후 숙박 고객님께 객실 키는 새롭게 발급 해주셔야 합니다.
- 병합 진행 예약은 퇴실 일시가 병합 요청의 예약만큼 수정됩니다. 다만 결제 내역은 수정사항 없이 각각 별개의 결제 일시와 입실일시로 확인됩니다.

      - 병합으로 인해 예약 건들의 더해진 숙박 이용 시간과 별개로숙박으로 만들어진 예약은 박수가 더해집니다.

## 병합 취소하는 방법

- 클라우드 내 대시보드에서 객실 선택 → \[예약 병합 내역\] 버튼 클릭 → \[병합 취소\] 버튼으로 취소 해주세요.
- 또는 예악 건 상세보기 우측 \[예약 병합 내역\] 버튼 클릭 → \[병합 취소\] 버튼으로 취소 해주세요.

### 병합 취소 후 퇴실 시간이 바뀌지 않는 경우

병합 취소 후 예약 수정으로 퇴실 일시를 조정해주세요.

<Callout>
  #### ❓자주 묻는 질문

  <AccordionGroup>
    <Accordion title="다가오는 예약을 배정 했는데 갑자기 사라졌어요!">

      대시보드 우측 \[사용기록\]에서 병합 이력을 확인해주세요. 실수로 병합하였다면 병합취소 해주세요
    </Accordion>

    </Accordion>

    <Accordion title="병합한 예약만 보고싶어요!">

    </Accordion>

      - 현재 투숙중인 예약에 미래 예약을 배정하기 원하신다면 다가오는 예약에 미래 예약이 뜰 때 병합해야합니다.

      ① 예약 카드 위에 마우스를 올려주세요.
