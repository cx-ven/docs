# 1세대 키오스크 회수함 위치

<img
  src="/images/HW_1세대_회수함.png"
  alt="Image"
  title="Image"
  style={{ width:"50%" }}
/>

<Info>
  대시보드에 '방출기 회수통 가득참' 사용기록이 보이는 경우, **회수함 통에 있는 키를 모두 제거해주세요.**

  데이터를 정상적으로 씌울 수 없는 키일 경우 방출하지 않고 회수함에 적재합니다. 회수함에 있는 키는 별도 보관이 필요하며 재사용을 권장하지 않습니다.
</Info>

<Warning>
  **회수함 장착 시 끝까지 밀어 넣어주세요.**

  끝까지 밀어 넣지 않으면 센서가 가려져 ‘회수통 가득참’으로 인식되어 키 회수/방출이 제한될 수 있습니다.
</Warning>

# 현금 방출기 권종 바꾸는 법

클라우드 우측 하단 \[설정\] → \[키오스크 설정\] → 좌측 사용하는 키오스크 선택

**1번 현금 방출기** - 키오스크를 정면으로 봤을 때 왼쪽 함의 방출 권종을 설정합니다.

**2번 현금 방출기** - 키오스크를 정면으로 봤을 때 오른쪽 함의 방출 권종을 설정합니다.

- 설정 가능한 권종은 5만원, 1만원, 5천원, 천원 입니다.
- 두 방출기의 권종이 동일한 경우 오류가 발생 될 수 있습니다. 1번/2번 현금 방출기는 다른 권종으로 설정 해주세요.
