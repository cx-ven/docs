# 3세대 키오스크 회수함 위치

대시보드 우측 사용기록에 \*\*‘방출기 회수통 가득참’\*\*이 표시되면, 키오스크 하부장을 열고 적재함 아래 회수함의 키를 꺼내 주세요.

꺼낸 키는 깨짐이나 이물질 여부를 확인한 뒤, 이상이 없으면 **적재함 맨 아래에 넣고 정상 발급 여부를 확인**해 주시기 바랍니다.\
확인 없이 넣을 경우 이후 발급이 실패할 수 있습니다.

---

<Callout>
  # 키오스크 영수증 교체하는 방법

  1. 영상과 같이 영수증(감열지)를 교체합니다.

  <video src="/videos/영수증교체방법영상.webm" controls style={{ width: "100%", maxWidth: "400px" }} />

  2. 키오스크 프로그램을 재실행합니다.

  > ① 키오스크 메인 화면 상단 중앙 부분 \[디지털 시계 부분\]을 연속으로 터치 5번\
  > ② \[고급 관리 모드\] 선택 → 암호 입력 (하단 중앙 문의 연락처 끝 4자리 숫자)\
  > ③ 키오스크 프로그램 재시작 터치 → 30초 내 프로그램이 자동 실행됩니다.
</Callout>

\[참고\] 영수증을 뒤집어 장착, 종이를 잡아주는 립 결착이 헐렁함, 종이가 끼였을 때 정상적으로 출력되지 않을 수 있습니다
