# 3세대 키오스크 물리 전원 위치

키오스크 전원이 꺼진 후 자동으로 재부팅이 안됐을 때 물리 전원 버튼을 눌러 켜주세요

<img
  src="/images/image.png"
  alt="Image"
  style={{ width:"50%" }}
/>

왼쪽부터 버튼 설명

**\[PC 버튼\]** : 눌렀을 때 컴퓨터 부팅 되는 소리가 나야 합니다.

**\[IO\]** : 현금방출기, 현금투입기 전원이 들어오며 기계음 소리가 나야합니다.

• 불빛(LED)은 전원이 꺼져 있거나 켜져 있는 상태와 관계없이 **항상 켜져 있습니다**\
• 전원 버튼은 **버튼이 안으로 눌려 들어가 있는 상태가 ‘켜짐’ 상태**입니다.\
• 전원 버튼을 한 번 더 눌러 버튼이 튀어나오면 '꺼짐'상태 입니다.

**\[디스펜서\] :** 카드 키 방출,회수하는 디스펜서의 전원이 들어오며 기계음 소리가 나야합니다.

• 불빛(LED)은 전원이 꺼져 있거나 켜져 있는 상태와 관계없이 **항상 켜져 있습니다**\
• 전원 버튼은 **버튼이 안으로 눌려 들어가 있는 상태가 ‘켜짐’ 상태**입니다.\
• 전원 버튼을 한 번 더 눌러 버튼이 튀어나오면 '꺼짐'상태 입니다.

# 3세대 키오스크 회수함 위치

대시보드 우측 사용기록에 \*\*‘방출기 회수통 가득참’\*\*이 표시되면, 키오스크 하부장을 열고 적재함 아래 회수함의 키를 꺼내 주세요.

꺼낸 키는 깨짐이나 이물질 여부를 확인한 뒤, 이상이 없으면 **적재함 맨 아래에 넣고 정상 발급 여부를 확인**해 주시기 바랍니다.\
확인 없이 넣을 경우 이후 발급이 실패할 수 있습니다.
